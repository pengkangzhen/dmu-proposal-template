# 专业学位硕士研究生-开题报告LaTeX模板

基于《附件1-专业学位硕士研究生学位论文开题报告（模板）.doc》（大连海事大学研究生院制 2019年1月版）
逐元素转制的 LaTeX 空表单模板，XeLaTeX + ctexart 编译。

## 编译

```bash
xelatex 开题报告模板.tex   # 连续两遍（longtable 列宽需第二遍稳定）
# 或
make
```

生成 `开题报告模板.pdf`（8 页：封面 / 填写说明 / 表单主体 6 页）。

## 版式对应（逐元素取自 .doc 字体表）

| 元素 | 字体 |
|------|------|
| 封面标题 / 学位论文开题报告 | 一号宋体加粗 |
| （专业学位） | 二号宋体加粗 |
| 封面信息栏 / 研究生院制 | 三号宋体加粗（下划线栏） |
| 说明页标题 | 三号黑体 |
| 表格节标题（一~六）及 1/2/3 小标题 | 小三宋体加粗 |
| 参考文献表头（序号/文献目录） | 小四黑体 |
| 签名/日期/评审签名 | 四号宋体 |
| 评价区（评价结果/等级/评语） | 四号仿宋（标签加粗） |

## 填写方法

1. **封面信息**：只改文件内「封面信息区」8 个宏（`\姓名`~`\开题时间`），封面与表格内论文题目自动同步；
2. **各节内容**：删掉对应的 `\ktblank{n}` 占位空白，直接书写普通文本与列表；
3. **参考文献**：删除表格中的 30 行空白，改用 `\ktref{作者. 题目[J]. 刊物名, 出版年: 页次.}`（序号自动编号）；
4. **研究计划**：复制 `\ktsched{时间}{研究内容}{预期目标和预期效果}` 增行。

版面约定：「四、研究计划」与「五、指导教师意见」固定同页；「六、开题报告会记录」与「六、论文选题评价结果」固定同页；其余各节盒子自动铺满所在页。

## 字体说明

模板优先加载 **Word for Mac 自带中文字体**（Simsun.ttc / SimHei.ttf / Fangsong.ttf，路径
`/Applications/Microsoft Word.app/Contents/Resources/DFonts/`），与 Word 打开原 .doc 的观感一致；
无 Word 时自动回退 macOS Songti SC / STSong，加粗为合成加粗（同 Word 机制）。
Windows 用户可将字体块替换为 `fontset=windows` 相应字体。

注意：各节盒子内只写普通文本，勿放表格、大图等不可跨页内容。
